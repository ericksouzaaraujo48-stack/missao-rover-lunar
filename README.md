#  Rover — Sistema de Inicialização

Projeto desenvolvido em **Python** que simula a inicialização dos sistemas de um rover, exibindo informações básicas sobre seu funcionamento.

## 📋 Sobre o projeto

O programa possui uma função responsável por iniciar o rover e apresentar no terminal o status de seus principais sistemas:

* Inicialização dos sistemas do rover;
* Verificação dos painéis solares;
* Exibição do nível da bateria.

Atualmente, o sistema considera a bateria com **100% de carga** e os painéis solares como funcionando normalmente.

## 🛠️ Tecnologias utilizadas

* **Python 3**

## 📂 Estrutura do projeto

